    How it works

    1

    Clean

    Source tags, links and image credits are removed so the model judges the writing, not the publisher.

    2

    Tokenise

    Text is split into BERT sub-word tokens. Long articles are cut into overlapping 256-token chunks.

    3

    Classify

    A fine-tuned BERT model scores each chunk; the scores are averaged into one prediction.

    4

    Explain

    Confidence below 65% is shown as Uncertain; very short inputs get a warning.

    Note: the model estimates whether text reads like reliable news or misinformation, based on patterns learned from labelled articles. It does not check facts against a knowledge source, so always verify important claims with trusted outlets.
