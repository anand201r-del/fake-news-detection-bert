About this project

Fake News Detection using Deep Learning and NLP.

Overview

TruthLens classifies news text as likely real or likely fake using a BERT transformer fine-tuned on labelled news articles.

The first version scored 99.99% but labelled almost every typed sentence as fake. The cause was a data leak: nearly every real article in the dataset began with “WASHINGTON (Reuters) –”, so the model learned the source tag instead of the language.

This version removes those source fingerprints, splits the data by article before augmentation, and trains on headlines, short snippets, paragraphs and full articles. It reaches 97.6% accuracy overall and 99.5% on full articles on a leak-free test set.

Project steps

  1. Data cleaning and leak removal (Reuters datelines, image credits, links)
  2. Leak check with a TF-IDF + Logistic Regression baseline
  3. Mixed-length augmentation, with the split done first
  4. Fine-tuning bert-base-uncased on a Colab T4 GPU
  5. Evaluation by input length; chunked inference for long articles
  6. Flask web application with REST API (/api/predict)
